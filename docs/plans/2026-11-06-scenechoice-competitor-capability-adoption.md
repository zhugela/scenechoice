# SceneChoice 竞品能力吸收决策

> 状态：已确认｜日期：2026-11-06｜决策：分阶段融合，不直接复制竞品

## 1. 决策摘要

SceneChoice 采用以下组合方向：

> InteractiveNovel 的易用性 + AI Story Gen 的可控规则 + openovel 的 Agent 分层 + Aventuras 的工程质量。

这不是把四个项目的功能一次性搬进 MVP。每项能力必须服务当前阶段目标，通过阶段门后才能进入下一阶段。竞品代码只用于研究设计和工程方法，不直接复制实现。

## 2. 吸收原则

1. 产品定位不变：5～10 分钟完成一部 3 集或 5 集互动短剧；
2. 规则决定事实和选择后果，AI 负责叙述；
3. 先完成单一可靠流程，再增加后台 Agent 和长期记忆；
4. 每项能力必须有测试、可观测数据和明确验收条件；
5. 不因竞品已有某功能就自动加入 SceneChoice；
6. 不复制竞品源码、品牌、文案、素材或故事内容。

## 3. 分阶段能力映射

### M1：故事规划 PoC

吸收：

- InteractiveNovel：低门槛创建流程和明确的生成等待反馈；
- Aventuras：模型调用、Prompt、Schema、业务校验分层；
- 四个项目：模型失败、格式错误和超时的降级思路。

本阶段实现：一句灵感生成完整 3/5 集蓝图、两个动态状态、固定二选一和至少三种可达结局。

本阶段不实现：数据库、正文生成、RAG、多 Agent、分支预生成。

### M2：领域模型与持久化

吸收：

- AI Story Gen：世界事实与自然语言叙述分离；
- Aventuras：SQLite 迁移、事务边界、状态变化记录；
- InteractiveNovel：故事恢复和阅读进度保存的产品体验。

本阶段实现：Story、Character、Episode、Choice、Metric、Ending，以及可恢复的故事存档。

### M3：互动执行引擎

吸收：

- AI Story Gen：选择合法性、确定性后果计算、状态机；
- InteractiveNovel：在用户阅读当前集时预生成下一步候选内容；
- Aventuras：生成阶段拆分、非关键步骤失败时降级。

本阶段实现：选择提交、状态变化、下一集生成、结局判定和幂等保护。AI 不得直接写数据库或绕过规则引擎。

### M4：竖屏 Web 体验

吸收：

- InteractiveNovel：主题创建、阅读字号、日夜模式、阅读位置和生成反馈；
- Aventuras：清晰的生成阶段状态和可恢复错误体验。

本阶段实现：Vue 3 + TypeScript 的创建、阅读、选择、状态变化和结局卡片完整闭环。

### M5：质量、开源与发布

吸收：

- openovel：前台叙述与后台整理分离的双循环思想；
- Aventuras：模型适配层、Token/耗时记录、CI、数据库迁移与发布文档；
- 四个项目：README、示例、架构图、贡献指南和公开评测。

MVP 只允许一个轻量后台任务：正文完成后异步生成摘要或质量检查。完整后台 Agent 团队后置到 V2。

## 4. V2 Backlog

以下能力有价值，但不进入首个公开版本：

- Storykeeper 后台 Agent；
- 条件激活的上下文卡；
- 长期记忆和向量检索；
- 多模型 Agent Profile；
- 完整分支回滚和时间旅行；
- 多人直播投票；
- 作品社区、排行榜和支付；
- AI 图片、语音和视频生成。

进入 V2 的前提：MVP 已有至少 10 位真实用户，核心完成率和一致性指标达到立项书要求，并有用户反馈证明该能力解决真实问题。

## 5. 禁止照搬清单

- 不采用 InteractiveNovel 的单文件大后端结构；
- 不采用宽松正则兜底替代强 Schema 校验；
- 不采用 AI Story Gen 的完整 RPG 战斗、经济、天气和阵营系统；
- 不在 MVP 引入 openovel 的多 Agent 团队；
- 不引入 Aventuras 的 Tauri、Rust、移动端同步和四十余个迁移复杂度；
- 不预生成整棵分支树，避免成本指数增长。

## 6. 各阶段验收问题

开发任何竞品启发功能前，必须回答：

1. 它解决哪个已确认的用户问题？
2. 为什么必须在当前阶段做？
3. 最小实现是什么？
4. 如何自动测试？
5. 如何观察效果、耗时和成本？
6. 韩立能否解释、修改并回答相关面试题？

任何一项答不清楚，该能力进入 Backlog，不进入当前迭代。

本地研究副本位于 `research/competitors/`，已被 `.gitignore` 排除：

- `InteractiveNovel/`：产品流程与前端状态；

- `Aventuras/`：模型适配、状态追踪和工程规范。
